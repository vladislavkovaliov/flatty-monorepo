## Типовые проблемы

### Бот не запускается

- Проверить `BOT_TOKEN` в `.env`.
- Проверить, что `.env` существует и не попал в git (использовать `.env.example` как шаблон).

### Ожидаются реальные загрузки, а файла нет

- На MVP `TEST_MODE=true` — реальных загрузок нет по определению. FakeTorrentProvider только симулирует прогресс.

### Логи содержат чувствительные данные

- Никогда не логировать: `BOT_TOKEN`, `QBITTORRENT_PASSWORD`, `NAS_PASSWORD`, `REDIS_PASSWORD`, `DATABASE_PASSWORD`, NAS credentials, private keys.

### Некорректная magnet-ссылка

- Парсер обязан валидировать схему `magnet:?` и наличие info hash; отсутствие `dn` / `tr` / `xl` — не ошибка.

### Проблемы с производительностью UI (будущее)

- Не редактировать Telegram message каждую секунду; опрос qBittorrent — задача Background Worker (FEAT-016), не handlers.
